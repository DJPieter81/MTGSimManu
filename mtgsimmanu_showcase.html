Three layers, one boundary rule

Rules go down. Choices go up. Never the reverse.

The engine enforces Magic's rules and knows nothing about strategy. The AI makes every choice and touches no game state directly. Card-specific knowledge lives in data — oracle text and gameplan JSON — never in source.

The abstraction contract

The rule that keeps 22,000 cards honest.

If fewer than ten of Modern's cards could legitimately hit this code path, you are not fixing a bug — you are patching a symptom. Stop, and find the mechanic.
No name gates

A CI ratchet blocks any commit that adds a card.name == "X" test in the engine or AI. The baseline is zero.

No magic numbers

Every scoring literal is a named, justified constant or is derived from a subsystem. A ratchet counts them per file.

Failing test first

The test goes red naming the mechanic, then the fix turns it green — both in the same commit.

One zone funnel

Every card that changes zone routes through a single call, so a dies- or enters-trigger can never be silently skipped.

Honest limits

The mechanic fixes are unit-verified and lifted the decks whose interaction was broken. They did not tame the aggro overperformers in best-of-three — Domain Zoo holds at 84.8% and the aggregate diagnosis says control loses on resource economy even when it sequences correctly. Creatures Toolbox stays at 14.8% by documented expectation: the effect-kind whitelist, not activation costs, is its gate. 32 of 96 calibration checks sit in band. Open problems are tracked below, not claimed as wins.

What's next.

Aggro resource economy across sideboarded matches
Domain Zoo at 84.8% is the top distortion. The aggregate diagnosis across every control loss delivers a structural verdict: control loses on resource economy even when it sequences its defense correctly. The kernel fix is scoped, not shipped.
Reanimator "keep-the-fatty" line
Payoff ETBs now resolve, but the AI under-executes the blink that saves a reanimated threat from its end-of-turn exile. Goryo's remains a fragile 28.8%.
Effect-kind whitelist for toolbox activations
Tranche 3 made sacrifice and discard costs payable, but Creatures Toolbox held at 14.8% — the acceptance doc names the effect-kind whitelist, not activation costs, as the actual gate. Documented expected, next tranche's target.
Haste-aware combat lines
Promoted to the highest-leverage remaining item after the payoff-gate measurement: the kernel undervalues haste threats' immediate clock impact when planning the turn.
